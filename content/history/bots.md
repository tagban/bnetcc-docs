A **bot** is a program that logs on to Battle.net the way a game does, without the game. Most are chat clients that sit in a channel. Others protect a channel, host games, run trivia or manage a clan. Pick a function to narrow the list.

Functions come from each bot's own readme, changelog, website or source code (archived copies where the sites are gone), and from people who ran them. A function that came from a plug-in or script is noted.

Every bot here has something to download. Bots that log on as a game still need to pass the [version check](/classic/versioning/), and most use a [BNLS server](/classic/versioning/bnls/) for it.

**Missing a bot, a version or a function?** The list is `data/bots.yaml` in the [repository](https://github.com/tagban/bnetcc-docs): edit it on GitHub, or tell us on [Discord](https://discord.gg/dR4djHweh3). Files in the archive are shared as they were found, for history and for community servers. Scan anything you download.

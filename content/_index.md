**Command Center** is a federated Classic Battle.net server written in Rust, and the software behind [bnet.cc](https://bnet.cc). This site documents how it works: the code, its structures and protocols, and how to run a server.

Command Center is **educational**: a study of how Classic Battle.net worked, written as a server anyone can read, build and run. It exists to keep games playable on **older computers and operating systems that once played on Battle.net and no longer can**, such as Mac OS 9 or Mac OS X 10.4 and earlier. It is not a replacement for Battle.net.

**If you have a relatively modern computer, buy the current games.** *Diablo II: Resurrected*, *Warcraft III: Reforged*, *StarCraft: Remastered* and *Warcraft II: Remastered* are well worth buying and play on the real Battle.net.

Command Center ships no Blizzard game files, CD keys or client patches. Battle.net, Diablo, StarCraft and Warcraft are trademarks or registered trademarks of Blizzard Entertainment, Inc.

Battle.net servers and related services, checked automatically **once a day**. "Online" means the server accepted a connection. The check never logs in or sends game data.

This list started from [BNETDocs' server list](https://bnetdocs.org/servers). To add or correct a server, edit [`data/servers.yaml`](https://github.com/tagban/bnetcc-docs/blob/main/data/servers.yaml) on GitHub.

Battle.net servers and the services around them, checked automatically **once a day**.

**What "Online" means.** The server accepted a connection, or a website answered a web request. The check never logs in or sends game data, so it can't tell whether every feature works. A server that shows offline for one day may simply have been briefly down.

**Where the list comes from.** It started from [BNETDocs' server list](https://bnetdocs.org/servers), and each entry links back to it and names who added it there. To add or correct a server, edit [`data/servers.yaml`](https://github.com/tagban/bnetcc-docs/blob/main/data/servers.yaml) on GitHub.

Battle.net's protocols were never published. Everything known about them comes from decades of work by players, bot authors and server developers. This page credits the people whose research this site builds on.

## Projects

- **[BNETDocs](https://bnetdocs.org/)**: the long-standing community protocol reference. Credited below and on each page it informed.
- **[Command Center](https://github.com/tagban/bnet_command_center)**: its protocol code has been tested against real clients and is this site's main source of verified facts.
- **[BNETDocs Atlas](https://github.com/BNETDocs/Atlas)** (MIT): a Battle.net server whose message handlers were used to cross-check layouts.
- **[gowarcraft3](https://github.com/nielsAD/gowarcraft3)**: an independent implementation used to cross-check framing and *Warcraft III* details.
- **[SC2Docs](https://superiority-sc2docs.pages.dev/), by Warrior**: the *StarCraft II* Battle.net 2.0 documentation this site's Battle.net 2.0 section is built on, used with his permission.
- **[d4-bnet-mitm](https://github.com/cjbrigato/d4-bnet-mitm)**: a *Diablo IV* Battle.net proxy used to cross-check Front framing.
